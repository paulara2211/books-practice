# Books Practice

A small Java project to practice object-oriented programming.

## What it does
- Defines a `Book` class with a title, an author and a number of pages.
- Creates two `Book` objects in `Main` and prints their description.

## Concepts practiced
- Classes and objects
- Constructors
- Encapsulation (private attributes)
- Methods

## Example output
"Clean Code" by Robert Martin, 464 pages.
"Tales of Mystery and Imagination" by Edgar Allan Poe, 230 pages.

## How to run
Open the project in Eclipse and run `Main.java` as a Java Application.
